Generator3DROOMS

Для работы 3D-сцены, импорта моделей и экспорта нужен локальный HTTP-сервер. Открытие HTML двойным щелчком может блокировать загрузку модулей.

  1. Запусти Run-Generator3DROOMS.bat из корневой папки проекта.
  2. Оставь открытым окно сервера.
  3. Браузер откроет студию автоматически.

Если сайт уже запущен через HTTP, открой студию.

Для бесплатных 4K-моделей нужен интернет. Модели отбираются по данным о разрешении текстур в каталоге Poly Haven.
